\section{Background}

\subsection{A gentle overview of LULC classification}

\begin{frame}{Land Use and Land Cover (LULC)}
    \begin{columns}
        \begin{column}{0.5\textwidth}
            \small
            \begin{itemize}
                \item<1-> \alert{Land cover}: biophysical material covering the Earth's surface (e.g., water, vegetation, soil, structures, etc.) \cite{townshendLandCover1992}\ \alert{``What is there?''}
                \item<2-> \alert{Land use}: human interaction with the land cover (e.g., agriculture, forest practices, urban development, etc.) \cite{andersonLanduseClassificationSchemes1971,andersonLandUseLand1976}\ \alert{``How is it being used?''}
                \item<3-> LULC data are used in a wide range of disciplines, including agriculture, forestry, urban planning, and environmental science \cite{lovelandDevelopmentGlobalLand2000,grekousisOverview21Global2015, wulderLandCover2018}
            \end{itemize}
        \end{column}
        \begin{column}{0.5\textwidth}
            \vspace{-1cm}
            \begin{figure}
                \centering
                \includegraphics[height=0.9\textheight]{images/ms_lc_map.pdf}
                \vspace*{-0.5cm}
                \caption{Land cover map of Mississippi.}
                \label{fig:lulc_example}
            \end{figure}
        \end{column}
    \end{columns}
\end{frame}

\begin{frame}{Pixel-wise Classification}
    \begin{itemize}
        \item<1-> Traditional classifiers usually operate by transforming a feature vector into output class probabilities for a given pixel.
        \item<2-> Common data sources include:
        \begin{itemize}
            \item<3-> Surface reflectance data
            \item<4-> Derived spectral indices (i.e., NDVI, EVI, NDWI, etc.)
            \item<5-> Ancillary information (i.e., topography, soil, etc) \cite{kavzogluEffectsAuxiliaryAncillary2023,wulderLandCover2018}
        \end{itemize}
        \item<6-> Non-parametric, supervised classifiers are often used (e.g., Decision Trees, Random Forests, Support Vector Machines, etc.) \cite{gislasonRandomForestsLand2006,gislasonRandomForestsLand2006,bakerAdvancesClassificationLand1991}.
    \end{itemize}
\end{frame}

\begin{frame}{Data Requirements}
    \begin{itemize}
        \item<1-> While deep learning networks are powerful, their primary drawback is the amount of data required to train them.
        \item<2-> For example, ResNet-50, a popular CNN architecture, has over 25,000,000 parameters that need to be learned \cite{heDeepResidualLearning2015b}.
        \item<3-> For land cover, this is especially problematic, as high resolution data is complex and difficult to annotate at scale \cite{maTransferLearningEnvironmental2024}.
        \item<4-> One approach to mitigate this issue is to use \alert{transfer learning}, where a network can be \alert{pre-trained} on a related task with a large amount of data, then \alert{fine-tuned} on the target task with a smaller amount of data \cite{yosinskiHowTransferableAre2014}.
    \end{itemize}
\end{frame}

\begin{frame}{Transfer Learning}
    \begin{figure}
        \centering
        \includegraphics[height=0.8\textheight]{images/transfer_learning.png}
        \caption{Transfer learning paradigm.} \label{fig:transfer_learning}
    \end{figure}
\end{frame}

\begin{frame}{Denoising Autoencoder}
    \begin{itemize}
        \item<1-> While labeled data is optimal for pre-training, some pre-training tasks can be performed in a \alert{self-supervised} manner, where the network learns to predict some property of the input data without requiring labels \cite{liangRemoteSensingImage2018}.
        % 
        \item<2-> Denoising autoencoders are a type of CNN that are trained to remove noise from an input image \cite{gondaraMedicalImageDenoising2016}.
        \item<3-> In effect, noise is added to an input image, then train the network to predict the original image from the noisy image.
        \item<4-> The network needs to learn \alert{features} that are \alert{robust} to noise while being meaningful for reconstruction \cite{vincentExtractingComposingRobust2008}.
    \end{itemize}
\end{frame}



\begin{frame}{Our Goal}
    \begin{itemize}
        \item<1-> Our overarching goal is to develop a 1m resolution land cover map that covers the entire state of Mississippi with a high degree of accuracy.
        \item<2-> Data annotation is expensive and time-consuming, so the main focus of our work is to devise a creative pre-training strategy that combines self-supervised pre-training with a supervised fine-tuning stage to reduce the amount of labeled data required for training a deep model.
        \item<3-> We construct a large U-Net model that undergoes various pre-training regimens, then fine-tune the model on only \alert{119} tiles of fully annotated data from the state of Mississippi.
        \item<4-> Transfer learning is not an uncommon approach, but self-supervised pre-training is not common in the remote sensing community --- especially in the context of land cover classification. As such, we are most interested in the performance of our self-supervised model.
    \end{itemize}
\end{frame}

\section{Conclusion}

\begin{frame}{Summary}
    \begin{itemize}
        \item<1-> Large scale pre-training of a deep model using an unsupervised regimen can enable the training of an over-parameterized deep model on a small amount of labeled data.
        \item<2-> Further, additional pre-training using a modest amount of labeled data can boost the performance of the model even further.
        \item<3-> Still, classifying more visually intricate land cover classes remains a challenge, even with a large model.
    \end{itemize}
\end{frame}

\begin{frame}{Future Works}
    \begin{itemize}
        \item<1-> More data --- clear need to improve the accuracy of cultivated crops and barren land classes.
        \item<2-> Post-processing using OBIA-inspired techniques to refine classification map edges.
        \item<3-> Applying model to super-resolved satellite imagery.
    \end{itemize}
\end{frame}
