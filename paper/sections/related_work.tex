Characterizing the Earth surface in a data-driven manner has long been a central topic of research in the remote sensing community \citep{andersonLanduseClassificationSchemes1971, cihlarLandCoverMapping2000, friedlGlobalLandCover2002, phiriDevelopmentsLandsatLand2017, zhaoComparisonThreeMachine2024}.
Early efforts into automated land cover classification algorithms emerged in the 1970s and 1980s, coinciding with the early days of satellite remote sensing \citep{tuckerAfricanLandCoverClassification1985,andersonLandUseLand1976,byrneMonitoringLandcoverChange1980}.
Many of these efforts utilized parametric models to assign land cover classes to pixels in coarse resolution satellite imagery based on their spectral signatures or temporal trends \citep{defriesNDVIderivedLandCover1994,jensenSpectralTexturalFeatures1979,townshendCharacterizationClassificationSouth1987, marceauEvaluationGreylevelCooccurrence1990}.
Land cover classification methods matured in the late 1990s and early 2000s as computational resources became more widely available and non-parametric machine learning models were adopted for these pixel-wise classification tasks \citep{brodleyDecisionTreeClassification1997, friedlMODISCollection52010, palRandomForestClassifier2005,lovelandDevelopmentGlobalLand2000, huangAssessmentSupportVector2002}.
Despite the increased predictive capacity of these non-parametric models, classification of very high spatial resolution (VHSR) imagery (e.g., \(<\)5m GSD) remained a challenging task due the inherent complexity and heterogeneity of land cover at these finer spatial scales \citep{tongLandcoverClassificationHighresolution2020}.
\citet{woodcockFactorScaleRemote1987} demonstrated that local spectral variability in land cover classes substantially increases as the spatial resolution of imagery increases beyond 5 m, increasing the inherent intra-class variance and making pixel-wise classification of VHSR imagery inherently challenging \citep{cleveClassificationWildlandUrban2008}.
Object-based image analysis (OBIA) methods emerged in the early 2000s in an effort to address these challenges by grouping pixels into objects using a segmentation algorithm, then classifying these objects as a whole rather than classifying individual pixels \citep{blaschkeObjectOrientedImageProcessing2000a, blaschkeObjectBasedImage2010}.
One notable side effect of the OBIA paradigm is that it effectively introduced spatial context into the classification process, both in an indirect manner by setting the analysis unit according to the output of a segmentation algorithm and optionally in an explicit manner by incorporating shape descriptors into the feature vector passed to a classifier~\citep{blaschkeGeographicObjectBasedImage2014a, yeReviewAccuracyAssessment2018}.
The success of OBIA methods in VHSR land cover classification has been largely attributed to this direct consideration of spatial context in the classification workflow~\citep{balhaComparativeAnalysisDifferent2021}
% which is difficult to achieve with pixel-wise classification methods, even with intensive feature engineering to extract spatial features from the imagery using filters, texture measures.

However, despite the superiority of OBIA methods over their pixel-wise predecessors, these approaches have several notable drawbacks that have motivated research into alternative methods for classification of VHSR imagery.
Perhaps most obvious is the classification model's reliance on the preceding segmentation algorithm producing groups of pixels that meaningfully delineate objects in the source imagery in an accurate and reliable fashion.
Calibrating a segmentation algorithm to accomplish this is an ill-defined process that requires substantial human supervision, even before a classifier can be trained \citep{maReviewSupervisedObjectbased2017}.
A poor choice of segmentation algorithm or its parameters can substantially degrade performance, as objects extracted by the segmentation algorithm may group multiple objects with different land cover classes together or may fragment a single object into multiple segments \citep{hossainSegmentationObjectBasedImage2019}.
% Even if the so-called ``scale parameter'' for a given algorithm is chosen appropriately for a given area, the generalization capacity of an OBIA model is an oft-cited bottleneck \citep{hossainSegmentationObjectBasedImage2019}.
While multi-scale segmentation algorithms attempt to address these shortcomings, they introduce additional complexity into the classification process that makes developing and scaling these models for operational land cover mapping difficult~\citep{dragutAutomatedParameterisationMultiscale2014, mingScaleParameterSelection2015,haoSegmentationScaleEffect2021}.

Subsequently, the introduction of deep learning-driven convolutional neural networks (CNNs) for general-purpose image processing tasks in the broader computer vision research community sparked substantial interest from researchers in remote sensing looking to consolidate the multi-stage classification process into an end-to-end modeling framework capable of incorporating both spectral and spatial features into predictions.
CNNs utilize stacked convolutional kernels with learnable parameters to extract spatially-organized feature maps corresponding to the presence of spectral and spatial features in the input~\citep{krizhevskyImageNetClassificationDeep2012}.
Originally designed for image classification, \citet{longFullyConvolutionalNetworks2015} demonstrated that CNNs could generate dense pixel-wise classification maps by upsampling these feature maps to match the resolution of the input, then applying a simple linear classifier to each pixel in the upsampled feature maps.
Despite the relative simplicity of this approach compared to existing methods, these fully convolutional networks (FCNs) achieved state-of-the-art performance on difficult general-purpose semantic segmentation tasks.
The design of FCNs became a starting point for research into deep learning models designed explicitly for semantic segmentation, and works centered around integrating these models for classification of remotely sensed data soon followed~\citep{yuanReviewDeepLearning2021}.
\citet{sherrahFullyConvolutionalNetworks2016} was among the first to apply FCNs to land cover classification of VHSR imagery, demonstrating the end-to-end learning capacity of these models to create dense, pixel-wise land cover maps from high-resolution aerial imagery in a single stage.
\citet{diakogiannisResUNetdeepLearning2020} proposed ResUNet-a, a model that integrated modern deep learning techniques for multi-scale feature extraction and residual learning with a multi-task learning schema to achieve state-of-the-art performance on the ISPRS Potsdam dataset.
\citet{wangUNetFormerUNetlikeTransformer2022} proposed a hybrid CNN-Transformer semantic segmentation architecture that combines the spatial feature extraction capacity of CNNs with the long-range dependency modeling capability of self-attention mechanisms in Transformers to integrate global spatial context into predictions, achieving state-of-the-art performance on several benchmark datasets.
Given the widespread success of these models, deep learning has quickly become a popular modeling strategy for automated image analysis and classification of VHSR imagery in the remote sensing community~\citep{liDeepLearningUrban2024, zhaoLandUseLand2023}.

\subsection{Training data sampling strategies}

While deep learning semantic segmentation models have emerged as the predominant approach for land cover classification at VHSR, comparatively little work has been published on the selection of samples for training data compared to their pixel-wise counterparts.
Indeed, most research into the applications of these models to VHSR land cover are evaluated against benchmark datasets, such as the ISPRS Potsdam~\citep{2DSemanticLabeling} and Vaihingen~\citep{2DSemanticLabel} 2D Semantic Labelling Challenges.
These datasets are valuable for determining the efficacy of new models and techniques in the context of existing works, but they ignore critical considerations required for operational applications of these models.
Given the data-hungry nature of deep learning models and the importance of quality training data, the selection of appropriate training data is critically understudied in the context of semantic segmentation models for land cover classification at VHSR, particularly when compared to their pixel-wise counterparts.
Training data selection strategies for traditional models have been widely studied to determine best approaches for maximizing model performance under real-world constraints, such as limited budgets for data collection and annotation~\citep{millardImportanceTrainingData2015}.
A common theme in these works is the integration of prior knowledge of the distribution of land cover classes over the area of interest to inform the sampling strategy~\citep{canoImprovedForestcoverMapping2017, brownLessonsLearnedImplementing2020,dongStratifiedEvenSampling2020, zhouTrainingDataSelection2020}.
\citet{jinAssessingImpactTraining2014} showed that selecting training data points proportionally to the area of each land cover class in an existing reference dataset improved the overall accuracy of a pixel-wise urban land cover classifier.
\citet{zhuOptimizingSelectionTraining2016} demonstrated that stratifying the study area according to land cover classes from and sampling training data proportional to the total area of each class maximized classification accuracy for pixel-wise land cover classification, while enforcing a minimum and maximum number of samples per class to avoid extreme class imbalance in the training data.

However, translating these strategies for selection of patches for training semantic segmentation models presents fundamental challenges.
Perhaps the most obvious problem is that a single patch may contain multiple land cover classes, complicating the process of selecting patches to achieve a desired distribution of classes in the training data.
Furthermore, as the predictive ability of semantic segmentation models is derived from their spatial feature extraction capabilities, there is also a pertinent question of how to select patches that contain meaningful spatial heterogeneity in land cover classes to maximize the variability of spatial features present in the training data.
% For example, a simple random sampling of patches over a predominantly homogeneous area may yield many patches containing a single land cover class with little variation in the spatial arrangement of that class and its interactions with other classes.
Consequently, there is a need for research into effective sampling strategies for training data selection for semantic segmentation models applied to land cover classification.
Our work addresses this gap by proposing a semantic stratification approach for selecting high-quality training data for VHSR land cover classification using a semantic segmentation model by stratifying according to feature representations derived from medium-resolution land cover data to address these challenges.

\subsection{Remote sensing pre-training and self-supervised learning}

Beyond the selection of high-quality training data, the performance of deep learning models in low-data regimes can be further improved through effective pre-training.
The data-hungry nature of deep learning models has motivated research into techniques for improving model performance and generalization under limited training data scenarios across many domains~\citep{adadiSurveyDataefficientAlgorithms2021}.
Transfer learning has long been among the most widely adopted techniques for addressing this challenge, particularly in the context of computer vision~\citep{zhouTrainingDataSelection2020}.
Notably, \citet{yosinskiHowTransferableAre2014} noticed that the convolutional kernels learned in the first layer of CNNs tended to resemble traditional image processing filters (e.g., Gabor filters), regardless of the dataset or training schema.
From this observation, they demonstrated that these low-level features are broadly transferable across different datasets and tasks, and demonstrated that initializing a model using parameters from a pre-trained model then fine-tuning on a different dataset substantially improved the model generalization capacity.
% In computer vision, who demonstrated that a two-stage training process where a model is first pre-trained on a large dataset (i.e., source domain) before being fine-tuned on a smaller dataset relevant to the desired task (i.e., target domain) could substantially improve model performance, generalization, and convergence speed compared to training a model from random initialization using only the target domain data.
% The predominant hypothesis for the success of transfer learning in deep learning is that the pre-training process enables a model to learn to extract high-level features from the input data that can be effectively repurposed during the fine-tuning stage, and that large-scale pre-training enables the model to learn to extract strong features that are difficult to capture using the smaller target domain dataset alone \note{CITE}.
The success of transfer learning has been widely demonstrated in the computer vision community, where a common practice is to pre-train models using the ImageNet Large Scale Visual Recognition Challenge (ILSVRC) dataset~\citep{yosinskiHowTransferableAre2014} before fine-tuning these models on smaller datasets for a variety of downstream tasks \citep{huhWhatMakesImageNet2016}.

\citet{maTransferLearningEnvironmental2024} documented the widespread adoption of transfer learning in remote sensing applications, noting that \num{92}\% of surveyed works utilized transfer learning to train deep learning models for remote sensing tasks.

However, they pointed out that while ImageNet pre-training is effective, using remote sensing-specific dataset for pre-training may yield better results due to the reduced domain shift between the source and target domains.
Further, remote sensing models are typically trained for sensor-specific tasks, with spectral bands and spatial resolutions that differ substantially from the natural images in ImageNet, further complicating both parameter transfer from ImageNet-pretrained models that expect 3-channel RGB inputs and the collection of large-scale labeled datasets with varying sensor sources for remote sensing-specific pre-training~\citep{xieTransferLearningDeep2016}.
As fully-supervised pre-training requires large-scale labeled datasets, which are relatively scarce in the remote sensing domain for VHSR imagery, there is a need for alternative pre-training strategies that reduce the reliance on labeled data~\citep{bastaniSatlasPretrainLargeScaleDataset2023,manasSeasonalContrastUnsupervised2021a,jeanTile2VecUnsupervisedRepresentation2019}.

As part of a larger movement in the machine learning community, self-supervised learning has emerged as a new paradigm for building large deep learning models that produce high-quality feature representations without the need for labeled data \citep{liuSelfSupervisedLearningGenerative2023}.
Like traditional supervised pre-training, self-supervised methods attempt to optimize a model with respect to some loss function that encourages the model to output a feature representation according to some desired properties.
In supervised learning, this loss function is typically defined through a comparison of the model's output to some ground truth label, while self-supervised methods define this loss function using some pre-text task where the model is trained to predict some property, augmentation, or transformation of the input data itself.
% For example, a common SSL approach for image data is reconstruction-based methods, where a model is trained to reconstruct the original input image from a corrupted version of the image
Historically, unsupervised representation learning from imagery was performed using reconstruction-based methods, where a model is trained to learn features from an input by reconstructing the original input from a low-dimensional representation using autoencoders~\citep{vincentExtractingComposingRobust2008,duStackedConvolutionalDenoising2017, xieSimMIMSimpleFramework2022}.
More recently, contrastive approaches have emerged as a strong alternative to reconstruction and fully-supervised pre-training methods: these contrastive methods train a model to produce similar feature representations for different augmented views of the same input while enforcing dissimilarity between feature representations of different inputs \citep{jaiswalSurveyContrastiveSelfSupervised2021}.
% SimCLR, among the most successful implementations of contrastive SSL, demosntrated that simple yet strong augmentations such as random cropping, color jittering, and Gaussian blurring were sufficient to learn high-quality feature representations using a deep CNN backbone \note{CITE}.
However, contrastive methods require large batch sizes due to the need for many negative samples to enforce dissimilarity between different inputs, which can induce substantial computational overhead during training and limit the size of models that can be trained \citep{chenSimpleFrameworkContrastive2020, chenWhyWeNeed2022}.
Modern reconstruction methods inspired by masked language modeling in natural language processing have emerged as a strong alternative to contrastive methods that do not require negative samples: these methods take advantage of the Vision Transformer (ViT) patching mechanism to randomly mask out a portion of the input image, then train the model to reconstruct the missing patches from the visible patches~\citep{heMaskedAutoencodersAre2022, xieSimMIMSimpleFramework2022}.
These masked image modeling (MIM) techniques have become the predominant self-supervised approaches in remote sensing for creating large foundation models, which are large pre-trained models that can be adapted for a wide variety of tasks and domains that ideally outperform models trained from scratch or use traditional supervised ImageNet pre-training \citep{sunRingMoRemoteSensing2023, jakubikFoundationModelsGeneralist2023, szwarcmanPrithviEO20VersatileMultiTemporal2025}.
Still, most MIM techniques require ViT backbones as they require the patching mechanism and global feature extraction capacity of attention mechanisms.
While powerful, ViTs lack the inductive biases toward imagery that make CNNs effective at extracting spatial features from images \citep{adadiSurveyDataefficientAlgorithms2021}, and research into MIM methods for CNNs is emerging \citep{liArchitectureAgnosticMaskedImage2023,tianDesigningBERTConvolutional2023, wooConvNeXtV2CoDesigning2023}, these methods are rather nascent and have not been widely adopted~\citep{hondruMaskedImageModeling2025}.
% ViTs have also not yet been widely adopted in the remote sensing community for VHSR land cover classification tasks, with the exception of a few notable works that demonstrate their utility in providing marginal improvements over CNNs on benchmark datasets, but real-world data constraints are typically not thoroughly considered \note{CITE}.
This is problematic, as ViTs typically only begin to outperform CNNs when pre-trained on very large datasets~\citep{dosovitskiyImageWorth16x162020}, a practical consideration for researchers and practitioners who must balance both computational resources and data availability when developing models.
Further, most foundation models for remote sensing are trained using massive datasets of unlabeled medium-resolution imagery, such as Sentinel-2 and Landsat~\citep{luVisionFoundationModels2025}.
While useful for global-scale tasks, a domain shift is still present between the medium-resolution sources and the meter-scale VHSR imagery necessary for land cover classification at these finer spatial scales.
Combined with the architectural considerations of ViTs, this creates a barrier to their adoption for operational VHSR land cover classification tasks, particularly under limited training data scenarios.
% Additionally, MIM techniques require long training schedules to converge, which can be computationally expensive and time-consuming, particularly when training using large datasets and backbones, making creating foundation models difficult for many researchers and practitioners without access to substantial computational resources \citep{heMaskedAutoencodersAre2022}.

Self-distillation techniques, such as BYOL~\citep{grillBootstrapYourOwn2020} and DINO~\citep{caronEmergingPropertiesSelfSupervised2021}, have recently emerged as alternatives to both contrastive and MIM approaches that can be used to learn strong feature representations without the need for negative samples, large batch sizes, or ViT backbones.
Like contrastive methods, self-distillation approaches largely revolve around maximizing the similarity between feature representations of different augmented views of the same input.
However, instead of relying on negative samples to prevent the network from learning trivial solutions, these methods utilize a teacher-student framework, where a student (or online) network is trained to predict the output of a teacher (or target) network that receives a different augmented view of the same input.
While the student network is trained directly using standard backpropagation and gradient descent algorithms, the teacher's parameters are updated using a momentum-based rule derived from the student's parameters.
As such, the teacher network is a slowly-evolving version of the student network that produces stable targets for the student to learn from, preventing the model from collapsing to trivial solutions.
Self-distillation methods are attractive for remote sensing applications due to their inherent flexibility and ability to learn strong feature representations using a variety of backbone architectures, including CNNs~\citep{chenExploringSimpleSiamese2020}.
% These techniques can be particularly useful for filling the gap between traditional supervised pre-training and MIM-based SSL approaches for training massive foundation models, where a more flexible approach that is data-efficient, architecture-agnostic, and computationally inexpensive is preferable.
Given the architectural constraints of MIM and the computational demands of contrastive methods, self-distillation techniques offer a compelling, architecture-agnostic solution suitable for pre-training CNNs on domain-specific, moderate-sized datasets
Subsequently, we employ BYOL as our approach to pre-training a CNN backbone using a moderate-sized (\(\sim\)400,000 samples) dataset of unlabeled VHSR imagery before fine-tuning this model for land cover classification using a very limited amount of labeled data.
